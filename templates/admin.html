College / Registrar console

Issue credentials, view the eligible set.

Roleplay the college registrar. You issue credentials to students — the only step where the college sees a name. You also manage courses and can review the submitted (already-anonymous) feedback. The verification path never consults the issuance log.

Step 1

Issue a credential

Enter a student name. The system generates a fresh secret x, computes Y = gx, adds Y to the eligible set, and returns the secret. Forward it to the student out-of-band — the server does not retain it.

Names exist only in the issuance log, never in stored feedback.
