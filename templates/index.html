Anonymous faculty feedback,
backed by a zero-knowledge proof.

AnonFeedback is a college mini-project demonstrating how a college can verify that feedback comes from an eligible student without being able to link a feedback response to that student's identity through the intended protocol. It uses a 1-out-of-n OR proof of set membership, with a course-scoped nullifier for duplicate prevention.

How the protocol works

A one-minute tour

  1. Setup. A safe prime p and a generator g of a prime-order subgroup are published. Every student has a secret x and a public key Y = gx.
  2. Issuance. The college adds each student's Y to the public eligible set S = {Y1, …, Yn}. The college sees the student's name only at this step.
  3. Proof. To submit feedback for a course, the student builds a 1-out-of-n OR proof: "I know x such that gx is one of the Yj in S — but I won't tell you which." The proof includes a course-scoped nullifier N = hx (where h is derived from the course id) so the same student cannot submit twice for the same course — yet the nullifier is unlinkable across courses and across students.
  4. Verify. The college checks the proof against S. It accepts if and only if the prover really did know a valid x. The proof transcript is statistically independent of which Yj was the student's, so the college cannot tell who submitted.

Full design, security model, and limitations are documented in plan.md and report.md.
